## Ollin 0.16.0 beta — persistencia para scripts y memoria de la IA

### Incluye

- `Save.Set/Get` para guardar datos propios de los scripts con la partida.
- Memoria de la IA: sigue el rastro unos segundos tras perder de vista al objetivo.
- Ejemplos de puertas persistentes y crafteo en la guía.
- 114 pruebas automatizadas.

### Instalación

1. Descarga `Ollin-Setup-0.16.0-beta.exe`.
2. Ejecútalo (Windows puede avisar por no estar firmado).
3. Abre **Ollin** desde el acceso directo.

Requiere .NET 8 Desktop Runtime.
