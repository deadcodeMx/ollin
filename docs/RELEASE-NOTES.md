## Ollin Beta 6.116.0 — Linux x64

### Añadido

- Editor y reproductor para **Linux x64**.
- Publicación self-contained.
- Paquete `Ollin-6.116.0-linux-x64.tar.gz`.
- Instalador Linux con `install.sh` y lanzador `.desktop`.
- Gamepad Linux por `/dev/input/js*`.
- Exportación de juegos con nombre de ejecutable y permisos según plataforma.
- Documentación en `docs/LINUX.md`.

### Limitaciones

- Audio silencioso en Linux; el resto del motor funciona.
- El instalador gráfico sigue siendo exclusivo de Windows.
