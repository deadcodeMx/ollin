## Ollin 0.13.0 beta — HUD y menús

### Incluye

- HUD para scripts: barras, etiquetas y mensajes temporales.
- Menú de pausa con Escape: continuar, reiniciar, detener y volumen maestro.
- Pantalla de fin de partida con reintentar o detener.
- Bandera `--play` para arrancar la reproducción al abrir un proyecto.
- 96 pruebas automatizadas.

### Instalación

1. Descarga `Ollin-Setup-0.13.0-beta.exe`.
2. Ejecútalo (Windows puede avisar por no estar firmado).
3. Abre **Ollin** desde el acceso directo.

Requiere .NET 8 Desktop Runtime.
