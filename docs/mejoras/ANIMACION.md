# Mejoras de animación y esqueletos

**Prioridad:** P1
**Estado:** Pendiente

## Objetivo

Animación 2D suficiente para personajes y efectos.

## Limitaciones

- Timeline editable básica.
- Curvas y eventos de frame limitados.
- Skinning con pesos no completo.
- Mezcla por capas limitada.
- FSM visual básica.
- Sin editor de curvas avanzado.

## Criterios de aceptación

- Timeline con curvas.
- Eventos de frame.
- Clips skeletal con pesos.
- Mezcla por capas.
- FSM visual.
- Pruebas.

## Tareas

- [ ] Curvas.
- [ ] Eventos.
- [ ] Pesos.
- [ ] Mezcla.
- [ ] FSM.

## Dependencias

Render y editor.
