# Mejoras del editor

**Prioridad:** P1
**Estado:** Pendiente

## Objetivo

Un editor cómodo y seguro para trabajo diario.

## Limitaciones

- Undo/redo no cubre todo el inspector.
- Edición multi-entidad limitada.
- Buscador/atajos básicos.
- Inspector genérico con campos limitados.
- Sin diff de scripts generados.
- Sin tests de UI.

## Criterios de aceptación

- Undo/redo consistente.
- Multi-edición.
- Buscador y atajos.
- Inspector sin desbordes.
- Pruebas de historial.
