# Mejoras de Linux

**Prioridad:** P1
**Estado:** Pendiente

## Objetivo

Que Linux sea una plataforma soportada, no experimental.

## Limitaciones

- Paquete Linux no validado en hardware real.
- Audio Linux sin probar.
- Gamepads Linux con campos no usados.
- Sin CI Linux.
- El paquete puede quedar atrás respecto a Windows.

## Criterios de aceptación

- Instalación y arranque en una distro real.
- Editor y player funcionando.
- Audio y gamepad.
- Paquete de cada release.
- CI Linux.

## Tareas

- [ ] Probar en hardware.
- [ ] Audio.
- [ ] Gamepad.
- [ ] CI.
- [ ] Paquete por release.

## Dependencias

Runtime, audio y release.
