# Validacion Ollin

Juego pequeno para validar el motor de principio a fin.

## Controles

- A / D o flechas: mover.
- Espacio / W / flecha arriba: saltar.
- E: interactuar.
- R: reintentar tras perder o completar.
- Pausa: menu de pausa del reproductor.

## Objetivo

Recoge las 3 monedas, evita al merodeador y llega a la meta turquesa.

## Validacion

- Menu de pausa: continuar, guardar, cargar, opciones y salir.
- Escena con tilemap, plataformas, camara, fisica, enemigo y HUD.
- Guardado en ranuras desde la pausa.
- Exportable con `Archivo -> Exportar juego`.
